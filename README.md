# App Store support and privacy pages

The public support and privacy pages that my App Store listings link to, served by GitHub Pages at the same addresses they've always had. The apps' source code is private.

| Path | App |
|---|---|
| `/air-today/` | Air Today |
| `/Flash-Note/` | Flash Note Pro |
| `/NoSleepPro/` | No Sleep Pro |
| `/SpeakerShame/` | Speaker Shame |
| `/TimeTravelPro/` | Time Travel Pro |
| `/vaultclipboard/` | VaultClipboard |

To change one of these pages, edit it here. The `docs/` folders (and Time Travel Pro's `gh-pages` branch) in the private app repos are no longer published.

MARCUS, Thinking Time, Solivo, SunSeeker, LocalMeet and FlushedGolf keep their pages in their own public repos (`marcus-privacy`, `thinking-time` and so on).
